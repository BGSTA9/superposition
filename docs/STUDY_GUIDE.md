# Study guide

An ordered path through the paper and this repository for a reader who knows Python, PyTorch
and linear algebra and is new to mechanistic interpretability. Each stop is:
**read** (paper pages) → **notebook** → **app page** → **explain it back** (questions) →
**exercises** (in the notebook).

This guide is filled in as notebooks and app pages land (PLAN.md). The final section, a menu of
extension projects drawn from the paper's open questions (pp. 45–46), is written in Phase 6.

## Stops

1. Orientation: notebook `00_orientation`.
2. Features, directions and superposition (pp. 1–8): notebook `01_features_directions_superposition`.
3. Demonstrating superposition (pp. 8–12): notebook `02_demonstrating_superposition`.
